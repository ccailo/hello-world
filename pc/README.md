# FlightVR PC Installer

Windows installer/bootstrapper for MSFS 2020 smartphone VR.

- Downloads official ALVR 20.8.0 Windows streamer
- Downloads PhoneVR 2.0.0-beta APK
- Configures Windows Firewall
- Detects SteamVR and sets its OpenXR runtime when possible
- Creates FlightVR desktop shortcut
- Writes setup instructions
- Built as a self-contained single-file Windows x64 executable

This branch is isolated from the repository's default branch.
